# Mustafa Cem | Kişisel Portfolyo Sitesi

Modern, duyarlı ve kullanıcı dostu bir kişisel portfolyo web sitesi. JavaScript ekosistemindeki en son teknolojiler kullanılarak geliştirilmiştir.

## Kullanılan Teknolojiler

- **Next.js 15** - React tabanlı web uygulaması çerçevesi
- **React 19** - Kullanıcı arayüzü kütüphanesi
- **TailwindCSS** - Utility-first CSS çerçevesi
- **Framer Motion** - Animasyon kütüphanesi
- **React Icons** - İkon kütüphanesi
- **Next Themes** - Koyu/açık tema desteği

## Özellikler

- ✅ Modern, temiz tasarım
- ✅ Tam duyarlı (responsive) arayüz
- ✅ Koyu/açık tema desteği
- ✅ Sayfa geçişlerinde animasyonlar
- ✅ SEO dostu meta etiketleri
- ✅ Terminal benzeri görsel öğeler

## Proje Yapısı

```
/app                    # Ana uygulama dizini (Next.js App Router)
  /about                # Hakkımda sayfası
  /skills               # Yetenekler sayfası
  /projects             # Projeler sayfası
  /contact              # İletişim sayfası
  layout.js             # Kök layout
  page.js               # Ana sayfa
/components             # Yeniden kullanılabilir bileşenler
  Footer.js             # Alt bilgi bileşeni
  Header.js             # Üst menü bileşeni
  Providers.js          # Context sağlayıcılar
  ThemeToggle.js        # Tema değiştirme bileşeni
/public                 # Statik dosyalar
```

## Sayfalar

- **Ana Sayfa** - Giriş, kısa tanıtım ve öne çıkan özellikler
- **Hakkımda** - Detaylı kişisel ve profesyonel bilgiler
- **Yetenekler** - Teknik ve profesyonel yetenekler
- **Projeler** - Öne çıkan projeler ve detayları
- **İletişim** - İletişim formu ve bilgileri
